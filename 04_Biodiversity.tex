\subsubsection{Scientific Questions of
Analysis}\label{scientific-questions-of-analysis}}

Scientific Question: Do hospitalized patients with major depressive
disorder (MDD) who have made a recent suicide attempt exhibit higher gut
microbial alpha diversity compared to MDD patients without a history of
suicide attempts?

Alpha diversity Null hypothesis: There is no difference in gut microbial
alpha diversity between hospitalized MDD patients with a recent suicide
attempt and those without a history of suicide attempts.

Alternative hypothesis: Hospitalized MDD patients with a recent suicide
attempt exhibit higher gut microbial alpha diversity compared to MDD
patients without a history of suicide attempts.

\hypertarget{interpretation-1}{%
\subsubsection{Interpretation 1}\label{interpretation-1}}

For the ggiNEXT and manual rarefaction curve plots, there should be
enough sequences to analyze for q = 1 and q = 2, but not for q = 0
because many curves in q = 0 are still increasing and have not fully
plateaued. Because of that, valid conclusion can be drawn on species
richness when q = 1 and q = 2, because the curves stabilize clearly.
However, it is probably not valid to draw conclusion when q = 0, because
some curves are still increasing.

\hypertarget{interpretation-2}{%
\subsubsection{Interpretation 2}\label{interpretation-2}}

Wilcoxon rank-sum tests using a one-sided alternative hypothesis showed
no significant differences in alpha diversity between suicide attempters
and non-attempters across all diversity levels. When q = 0, p value is
0.11. When q = 1, p value is 0.237. When q = 2, p value is 0.443.
Overall, these results fail to reject the null hypothesis and indicate
that hospitalized MDD patients with recent suicide attempts do not
exhibit significantly higher gut microbial alpha diversity compared to
those without a history of suicide attempts.

\hypertarget{interpretation-3}{%
\subsubsection{Interpretation 3}\label{interpretation-3}}

I statistically tested my scientific question using Wilcoxon rank-sum
tests to compare alpha diversity between suicide attempters and
non-attempters. I used this test because my variable of interest,
Attempt Status, is categorical, and my alpha diversity data were not
normally distributed, making a non-parametric test more appropriate than
ANOVA. I conducted separate one-sided Wilcoxon tests for richness (q =
0), Shannon diversity (q = 1), and Simpson diversity (q = 2), using an
alternative hypothesis that alpha diversity would be greater in
attempters compared to non-attempters. This allowed me to statistically
evaluate whether gut microbial diversity differed between groups across
all ASVs, common ASVs, and dominant ASVs.
